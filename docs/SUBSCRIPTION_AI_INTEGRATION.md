# Subscription providers — Claude Max 5x, ChatGPT, Grokbot

Quyết định hiện tại: chỉ Claude Max 5x, ChatGPT và Grokbot. Windows 10 localhost, bản Codex ở 127.0.0.1:3211 tách bản Claude 3210. Không mua API key, không tự bật overage/top-up/billing theo usage, không trích xuất OAuth/cookie/session. Gemini là adapter cũ optional/disabled; không triển khai thêm hoặc dùng để bù provider thiếu.

## ChatGPT / Codex CLI

**Bổ sung 04/11/2026 — account/quota chỉ đọc:** `Orbit.ps1 -Action check-codex` gọi app-server `stdio://` chính thức, handshake `initialize`/`initialized`, `account/read` với `refreshToken:false`; chỉ sau khi xác nhận auth type `chatgpt` mới gọi `account/rateLimits/read`. Không đọc auth.json hoặc lấy token; official CLI vẫn sở hữu auth/refresh thông thường. Không dùng external token provider. Client từ chối mọi server request, gồm yêu cầu refresh token qua bên thứ ba.

Quota request đặt `supportsLunaReserve:false` và `excludeResetCreditDetails:true`; không gọi consume reset-credit, gửi credit email, login/logout, config write, thread/turn hoặc command methods. Output chỉ có auth type, thời điểm và windows/usedPercent/reset do provider trả; không email/account ID/raw stderr/credit balance, không tự tính số token hoặc phần trăm còn lại. Không polling, không DB/probe receipt. Toàn bộ subprocess bị giới hạn thời gian/output và được dừng khi đọc xong hoặc hủy.

Contract đã đối chiếu bằng `codex app-server generate-ts` của đúng binary 0.166.0 và [GetAccountRateLimitsResponse](https://github.com/openai/codex/blob/rust-v0.166.0/codex-rs/app-server-protocol/schema/typescript/v2/GetAccountRateLimitsResponse.ts). `ordinaryUsageAllowed` là permission snapshot do backend trả, không bảo đảm billing của một inference tương lai. `null` giữ nguyên là chưa biết; không suy ra recovery từ phần trăm/reset time. Official signed-out account read đã chạy, không gọi model; signed-in quota còn CLI_STUB TESTED, chưa LIVE VERIFIED.

Giữ official `@openai/codex@0.166.0`, official `codex login` + forced_login_method=chatgpt; ORBIT không mở auth.json, copy token hoặc lấy cookie web. Non-interactive `codex exec` có JSONL, output schema, output file, ephemeral/read-only, ignore user config/rules; shell, unified_exec, multi-agent, apps/web search tắt. Bounded input/output, argv array/shell=false, scratch directory, AbortSignal/process-group cancellation, validated schema và checksum handoff giữ nguyên.

Child environment loại API keys/cloud credentials/database URL/Node options; profile ở `.orbit/codex/cli`. Official CLI tự quản lý auth. ORBIT không đồng bộ projects/agents/chat history và không đọc credential cache. CLI installed/login không đủ CONNECTED; quota còn lại trả null khi không có dữ liệu chính thức.

**Chốt only-included mới:** schema/config/help đã đọc chưa cho ORBIT cơ sở đã kiểm chứng để bảo đảm một request không dùng purchased credits/extra usage của tài khoản. Không tạo flag CLI giả, không nhận biến môi trường `...VERIFIED=true` làm bằng chứng và không sửa billing settings. `CLI_INCLUDED_ALLOWANCE_UNVERIFIED` chặn real invoke/probe **trước subprocess/model request**, descriptor unavailable cho LIVE và UI BLOCKED khi CLI có sẵn. CLI_STUB vẫn kiểm được giao thức nhưng không vượt gate. Chi phí local 0 cents không phải bằng chứng hóa đơn 0 hoặc chỉ dùng quota bao gồm.

Mở gate cần một cơ chế chính thức có thể kiểm chứng/thi hành only-included và nghiệm thu với tài khoản người dùng đã cho phép. Không yêu cầu mua API key hoặc dán tokens vào chat. Việc hỗ trợ login CLI vẫn có; ORBIT chưa gửi prompt thật trong lượt này.

Nguồn đã đọc: [Codex authentication docs](https://github.com/openai/codex/blob/main/docs/authentication.md), [non-interactive docs](https://github.com/openai/codex/blob/main/docs/exec.md), [official config schema](https://github.com/openai/codex/blob/main/codex-rs/core/config.schema.json), [config references](https://github.com/openai/codex/blob/main/docs/config.md), official binary `--version`, `exec --help`, `login --help/status`, `features list`. GitHub markdown redirects tới developers.openai.com; website docs này bị network policy 403 trong môi trường trước đó. Không coi thiếu một config field là kết luận vĩnh viễn rằng provider không hỗ trợ; đó là cơ sở giữ gate UNVERIFIED ở implementation hiện tại.

## Claude Max 5x: direct Claude Code và Agent SDK là hai phạm vi

Max 5x là gói người dùng khai báo. Việc sử dụng Claude Code chính thức với gói đó không tự chứng minh quyền đưa subscription vào một orchestrator bên thứ ba hoặc dùng OAuth qua Agent SDK. Technical headless support cũng không thay cho điều khoản/auth entitlement.

[Official Claude Code README](https://github.com/anthropics/claude-code/blob/main/README.md) mô tả sản phẩm terminal. [Agent SDK TypeScript README](https://github.com/anthropics/claude-agent-sdk-typescript/blob/main/README.md) nêu: “Use of this SDK is governed by Anthropic's Commercial Terms of Service”, kèm link [Commercial Terms](https://www.anthropic.com/legal/commercial-terms). [Agent SDK Python README](https://github.com/anthropics/claude-agent-sdk-python/blob/main/README.md) mô tả SDK và bundled CLI. Các README đã kiểm không xác lập rằng consumer Max quota dùng được qua ORBIT/SDK. Tài liệu pháp lý đầy đủ/điều kiện cá nhân chưa được kiểm chứng đủ trong lượt này; không kết luận trái chiều rằng mọi CLI automation đều bị cấm.

Giữ `MAX_SUBSCRIPTION_ORCHESTRATOR_ELIGIBILITY_UNVERIFIED`. Không cài Claude SDK/CLI, không gọi model, không đọc/chỉnh `~/.claude`, không copy codebase hoặc dùng `CLAUDE_CODE_OAUTH_TOKEN` làm đường thay thế. Cần xác minh chính thức quyền personal orchestration, auth method và only-included/quota behavior trước adapter runtime.

## Configuration, UI và kiểm thử

- Default order Claude Max 5x → ChatGPT/Codex → Grokbot. Gemini không có tile, version probe, install/login/probe hoặc runtime route mặc định. Adapter optional giữ cho regression, không tự bật vì thiếu reviewer. Google/Gemini mock tile cũng ẩn trong Local Mode.
- Paid REST bị khóa như trước ở registry/probe/transport. Không có purchase/overage/top-up endpoint hoặc command. Không hứa biết remaining allowance/invoice khi provider chưa cung cấp cơ chế được kiểm chứng.
- Core router không gán vai trò theo hãng; policy ở configuration/adapter boundary. Valid receipt cũ không vượt descriptor unavailable hoặc default-disabled Gemini. Live handoff vẫn cần hai eligible vendors; currently BLOCKED.
- Regression dùng các fixture đã có (kể cả optional Gemini CLI_STUB) để kiểm engine; không cài thêm Gemini hoặc chạy Google account. Official default install/status chỉ Codex. CLI_STUB/MOCK và synthetic receipts không thành LIVE.
- Tests thêm cho policy mặc định, Gemini reject trước invocation/receipt, only-included fail-closed, legacy-profile protection, separate cookies và coexistence với sentinel 3210. Chi tiết/evidence trong PROVIDER_CORRECTION_VALIDATION.md.
